# Website Marketing Funnel Analysis Dashboard

## Project Overview
Analyzed 309 marketing campaign records to understand the customer funnel — from impressions to orders.

## Tools Used
- Power BI
- Excel

## What I Did
- Analyzed impressions, clicks, leads, orders, and revenue
- Built KPI cards showing total impressions (2bn), clicks (3M), leads (66K), and revenue
- Created donut chart for spend by category
- Built bar chart for revenue by campaign
- Added line chart for daily revenue trend
- Added slicer for category filter

## Key Insights
- Total Impressions: 2 Billion
- Total Clicks: 3 Million
- Total Leads: 66K
- YouTube Blogger generated highest revenue (15.1M)
- Social category has highest spend (45.11%)
